# 판독에서 뺄 install_id — **내 자신의 방문** (C206)
#
# 왜 이 파일이 있나: `funnel.py`는 `probe-` 접두사가 붙은 시험 줄만 걸렀는데, 내가 그냥 브라우저로
# 라이브를 열어 확인하면 낯선 사람과 똑같은 모양의 install_id가 찍힌다. 그래서 내 확인이 표본에
# 섞였다. 2026-08-17에 잡았고, 8/13~14 자료 217행 중 71행(33%)이 내 것이었다. 빼기 전과 후 —
#
#     첫 판 시작  52% → 75%      60초 넘김  48% → 67%      두 번째 판  24% → 33%
#
# 원자료는 시트에 그대로 있고 이 파일은 **읽을 때만** 뺀다. 그래서 지난 날도 소급해서 다시 읽힌다.
# 시트의 '시험 줄 지우기' 메뉴는 행을 **실제로 지운다** — 그걸 쓰면 소급이 영영 안 되니 쓰지 않는다.
#
# ⚠**저장소에 넣어 둔다(git 밖에 두지 않는다).** `analytics_endpoint.txt`처럼 추적 밖에 두면 새로
# 클론한 곳에서 파일이 없고, 그러면 **조용히 안 걸러진 숫자**가 나온다. 이 프로젝트가 그 방식으로
# 이미 세 번 넘어졌다. install_id는 비밀이 아니라 내 브라우저에 찍힌 난수라 공개돼도 무해하다.
#
# ⚠**시크릿 창은 열 때마다 install_id가 새로 생긴다.** 그래서 이 목록은 과거를 고치는 자이지
# 앞으로를 막는 자가 아니다. 앞으로의 몫은 보내는 쪽에서 갈라야 한다 — 라이브 주소를 `?dev=1`로
# 열면 게임이 스스로 `probe-`를 달게 하는 것. 빌드를 다시 구워야 하므로 루프 2 경계(8/24) 몫이다.
#
# 쓰는 법: 한 줄에 install_id 하나. `#` 뒤는 설명. 내가 라이브를 확인한 날엔 여기 한 줄을 보탠다.
