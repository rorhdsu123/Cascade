# BlockCastle

**내려오는 적을 블록 퍼즐로 쓸어내는, 한 손으로 즐기는 코지 디펜스 퍼즐.**

규칙은 한 문장으로 끝납니다 — **줄을 채워 지우면, 그 줄에 있던 적이 함께 사라집니다.**
못 막은 적은 아래로 내려와 거점을 깎고, 거점이 무너지면 판이 끝납니다.

> 📌 **저장소 이름과 코드 곳곳의 `Cascade`는 개발 코드명입니다.** 게임 이름은 BlockCastle입니다.

## 어떤 게임인가

세로 화면 모바일 게임이고, 블록 퍼즐과 디펜스를 한 판에 겹쳐 놨습니다.

- **8×8 보드**에 조각을 끼워 넣습니다. 가로든 세로든 한 줄이 꽉 차면 그 줄이 지워집니다.
- 지워진 줄에 **적이 서 있었다면 같이 사라집니다.** 이게 이 게임의 유일한 공격 수단입니다.
- 조각을 몇 번 놓을 때마다 **적 전원이 한 칸씩 내려옵니다.** 하단까지 닿으면 거점이 깎이고,
  거점 HP가 0이 되면 패배입니다.
- 그래서 매 수가 두 가지 판단을 같이 요구합니다 — *조각을 어디에 끼울까*(퍼즐)와
  *이 줄을 어느 적에게 쓸까*(디펜스).

**모드는 둘이고, 둘 다 코어입니다.**

- **캠페인** — 14개 스테이지. 판마다 목표가 다릅니다: 버티기 · 수집 · 폭탄 해체 · 도둑 막기.
- **무한** — 끝없이 내려오는 적을 상대로 점수를 쌓고 자기 기록을 갱신합니다. 어두운 배경의 별도 톤.

## 직접 실행하려면

[Godot Engine 4.6](https://godotengine.org/) (GL Compatibility 렌더러)으로 만들었습니다.
저장소를 Godot에서 열고 실행하면 됩니다 — 별도 빌드 단계나 외부 의존성이 없습니다.

```
git clone <이 저장소>
# Godot 4.6에서 프로젝트 폴더를 열고 F5
```

- 진입점은 `Main.tscn` → `Main.gd`입니다.
- 안드로이드 빌드 절차(서명·템플릿·함정)는 [`docs/RELEASE.md`](docs/RELEASE.md)에 있습니다.

## 개발 방식에 대해

기획·아트는 사람 2인이 맡았고, **코드는 AI 페어(Claude)와의 협업으로 작성**했습니다.
그래서 이 저장소에는 결과물만이 아니라 **판단의 기록**이 같이 남아 있습니다.

- [`docs/SPEC.md`](docs/SPEC.md) 하단의 **결정 로그** — 무엇을 정했고, 왜 그렇게 정했고, 무엇을 기각했는가
- `stage_data.gd`의 주석 — 밸런스 수치가 감이 아니라 **봇 시뮬 실측**에서 나왔다는 증거.
  기각한 대안과 그 측정값도 같이 적혀 있습니다
- `tools/` — 위 실측을 실제로 돌린 프로브·회귀 하네스
- `CLAUDE.md` — AI 페어에게 주는 작업 규약. 여러 세션이 한 저장소를 동시에 만질 때의 규칙
- 커밋 히스토리 — 제목 끝의 `(C131)` 같은 ID가 결정 로그를 가리킵니다

상세한 협업 구조와 AI 활용 내역은 별도 제출 문서에 정리했습니다.
