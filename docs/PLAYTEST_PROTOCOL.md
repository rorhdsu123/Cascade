# Cascade — 사람 플테 관찰 프로토콜 (v1)

> Phase V W1 산출물 ②. **코드 0의 설계 문서** — 기계(애널리틱스)가 못 잡는 것을 사람 눈으로 잡는 계획.
> 짝 문서 = `ANALYTICS_TAXONOMY.md`(기계 몫). 작성 2026-07-24.

---

## 0. 원칙

1. **기계가 못 보는 것만 본다.** 숫자로 찍히는 건 애널리틱스 몫. 여기선 **표정·주저·소리내어 생각·"왜 그만뒀나"** — 맥락과 감정.
2. **가장 안 밝혀진 가정을 겨눈다.** "이 코어 루프가 사람을 붙잡느냐" + "코지라는데 실제로 코지하게 느끼나(포지셔닝)".
3. **끼어들지 않는다.** 막혀도 힌트 금지(막힘 자체가 데이터). 유일한 개입 = think-aloud 유도.
4. **판단은 패턴으로.** 1명의 말 ≠ 진실. 5~10명 중 **몇 명에게 같은 신호가 반복되나**로 읽는다.

## 1. 표본 & 세팅

| 항목 | 정함 |
|---|---|
| 인원 | **5~10명** (3명이면 신호 약함, 10명 넘으면 관찰 피로) |
| 구성 | 캐주얼 퍼즐 유저 위주 + 미드코어 1~2명(포지셔닝 양쪽 확인). 지인 편향 주의 — 솔직한 사람 |
| 기기 | **실기기 빌드**(에디터·웹 아님). 세로 손잡이 실감이 핵심 |
| 광고 | **없음.** 부활은 스텁으로 즉시 부활(전환 의사만 관찰, 실광고는 W2) |
| 장소 | 옆에 앉아 화면+표정 동시에 보이게. 조용한 1:1 |
| 시간 | 1인 **20~30분**(튜토리얼→8스테이지 일부→무한 1~2런) |
| 기록 | ①관찰시트(§4) 실시간 체크 + ②가능하면 **화면+얼굴 녹화**(동의 받고). 손으로 다 못 적음 |

> **관찰자 1인 = 피험자 1인** 권장. 적으면서 표정 보긴 벅참 — 녹화가 백업.

## 2. 세션 흐름

**시작 전 (2분)**
- "잘하는지 보는 게 아니라 **게임이 잘 만들어졌는지** 보는 거예요. 막혀도 그게 정보예요."
- "머릿속에 드는 생각을 **소리 내서** 말해주세요. 지루하면 지루하다고, 헷갈리면 헷갈린다고."
- 설명 **금지**. 룰 안 알려줌(튜토리얼이 그 일). 첫 화면만 열어주고 손 뗌.

**플레이 중 (§4 관찰)**
- 침묵하면 딱 한 마디: *"지금 무슨 생각 하세요?"* — 유도만, 방향 제시 X.
- 막혀도 힌트 X. 스스로 그만두면 그만두게 둠(그게 이탈 지점).

**끝난 뒤 (§6 인터뷰, 5분)**

## 3. 무엇을 겨누나 — 리스크 질문 → 관찰 신호

| 리스크 질문 | 사람 눈으로 잡을 신호 |
|---|---|
| **코어가 붙잡나** | 판 끝나고 **자발적으로 "한 판 더"** 하나 vs 관찰자 눈치 보며 계속하나 |
| **코지냐 미드코어냐** | 어깨·표정 — **편안**(코지)인가 **몰입 긴장/찡그림**(전략)인가. 본인 입으로 "머리 아프다"vs"편하다" |
| **참을까/터뜨릴까 긴장** | 콤보 쌓으려 **참는 순간의 몸짓**(멈칫·입술 깨묾) — 긴장이 재미인가 스트레스인가 |
| **죽음의 질(C60 재현)** | 죽는 순간 반응 — **"아 아까워"(재도전 의욕)** vs **"이건 뭐야/억울해"(짜증·이탈)** |
| **부활 누르나** | 죽고 부활 제안 떴을 때 **망설임 길이·표정**. 안 누르면 즉시 이유 물음 |
| **FTUE 이탈** | 튜토리얼 중 **한숨·건너뛰고 싶어함·"언제 끝나"** / 첫 줄 터뜨릴 때 **표정 밝아지나**(첫 도파민 성사) |
| **막힘 vs 거점사 체감** | 막혀 죽을 때 **"내가 잘못 놨네"(납득)** vs 거점사 때 **"손쓸 수가 없었어"(무력)** — 어느 죽음이 납득되나 |

## 5. think-aloud 유도 문구 (방향 제시 없는 것만)
- "지금 무슨 생각 하세요?"
- "방금 왜 그렇게 하셨어요?" (판단 안 함, 이유만)
- "지금 기분이 어때요?" (죽은 직후·막힌 직후)
- ❌ 금지: "저기다 놓으면 돼요", "그건 이렇게 하는 거예요"(= 개입, 데이터 오염)

## 6. 사후 인터뷰 (5분, 열린 질문)
1. **한 단어**로 이 게임 느낌은? (코지/전략/스트레스… 포지셔닝 직격)
2. 가장 **짜릿했던** 순간 / 가장 **답답했던** 순간?
3. 죽었을 때 **다시 하고 싶었나, 그만두고 싶었나?** 왜?
4. 광고 보고 **부활**하는 거 어떻게 느꼈나? (자연스러움/거슬림)
5. **혼자 집에서** 이걸 또 켤 것 같나? 어떤 기분일 때?
6. 스테이지(정해진 판) vs 무한 중 뭐가 더 끌렸나? 왜?
7. (안 물어봤는데 말하면 금) 헷갈리거나 불공평하게 느낀 것?

## 7. 기록 → 판단 (세션 후 집계)

**1인마다 3줄 요약**: ①붙잡았나(재도전 자발성) ②코지vs긴장 체감 ③죽음이 아까움인가 억울함인가.

**패턴 판정(전체 표본):**
| 신호 | 초록(진행) | 빨강(멈춤·재설계) |
|---|---|---|
| 자발적 "한 판 더" | 다수가 시킴 없이 | 관찰자 눈치로만 |
| 포지셔닝 | 본인 입 "편하다/재밌다" 다수 | "머리 아프다/피곤"이 다수 → 코지 UA 배신 |
| 죽음의 질 | '아까움'이 우세 | '억울함'이 특정 원인(주로 막힘)에 몰림 → C60 재현, **그 상황 우선 수정** |
| 부활 의사 | 망설임 짧게 누름 | 억울한 죽음 뒤 거절+이탈 |
| FTUE | 첫 줄에서 표정 밝아짐 | 튜토리얼 중 스킵 욕구·한숨 다수 |

> **가장 중요한 한 줄**: 표본 다수가 **시키지 않아도 "한 판 더"**를 누르면 코어는 붙잡는 것. 아니면 스펙터클·셸을 더 쌓기 전에 **코어 60초 자체**를 손봐야 한다.

## 8. 애널리틱스와의 분업 (겹침 방지)
| 이 문서(사람) | 애널리틱스(기계) |
|---|---|
| **왜** 그만뒀나(표정·말) | **어디서** 그만뒀나(이벤트) |
| 죽음이 억울한지(감정) | 죽음 원인 분포(cause) |
| 코지vs긴장 체감 | 세션 길이·재도전율 |
| 부활 **망설임·이유** | 부활 전환율(숫자) |

→ 사람 플테로 **가설**을 잡고, 애널리틱스로 **규모** 확인. 둘은 같은 리스크 질문(§3)을 다른 각도로 친다.

### 판독기 두 개 — 읽는 데이터가 다르다

| 도구 | 읽는 것 | 언제 |
|---|---|---|
| `python3 tools/funnel.py 이벤트.csv` | **구글 시트에 모인 남의 기기 데이터** | 웹 루프 1·2·3 판독 |
| `godot --headless --path . --script tools/analytics_report.gd` | 이 기기의 `analytics.jsonl` | 옆에서 보는 대면 플테·배선 점검 |

웹 자료는 전부 시트로 온다(비콘 경로, C182) — 웹 루프를 `analytics_report.gd`로 읽으려 하면
**내 기기 로그만 보고 "데이터가 없다"고 결론 내리게 된다.** 시트에서 꺼내는 법은
이벤트 시트 → 파일 → 다운로드 → CSV.

`funnel.py`는 세션 단위 **누적** 퍼널(세션 → 첫 판 → 60초 → 첫 클리어 → 두 번째 판)과
가장 크게 꺾이는 칸, 재방문·웹 D1, 빌드별 비교를 낸다. 통과선은 `ROADMAP.md` §3-C.

🔴**내가 확인한 방문은 표본이 아니다 — `tools/funnel_ignore.txt`에 install_id를 적어 둔다** (C206).
`probe-` 접두사만 걸러서는 안 걸린다. 내가 그냥 브라우저로 라이브를 열면 낯선 사람과 똑같은 모양의
install_id가 찍히기 때문이다. 2026-08-17에 잡았고, 8/13~14 자료 **217행 중 71행(33%)이 내 것**이었다.
빼기 전과 후가 이만큼 벌어진다 — 첫 판 시작 `52% → 75%` · 60초 넘김 `48% → 67%` · 두 번째 판 `24% → 33%`.

- **라이브를 확인한 날엔 그 install_id를 한 줄 보탠다.** 안 보태면 다음 판독이 조용히 오염된다.
- 어느 줄이 내 것인지는 `--keep-mine`으로 앞뒤를 대보면 갈린다. 뺀 결과는 화면 맨 위에 늘 찍힌다.
- ⚠**시크릿 창은 열 때마다 install_id가 새로 생긴다.** 이 목록은 과거를 고치는 자이지 앞으로를
  막는 자가 아니다. 앞으로의 몫은 보내는 쪽에서 갈라야 한다(라이브 주소 `?dev=1` → 루프 2 경계 8/24).
- ⚠시트 메뉴의 **'시험 줄 지우기'는 행을 실제로 지운다.** 원자료를 지우면 소급이 영영 안 되니
  판독에서 빼는 일에는 쓰지 않는다.
